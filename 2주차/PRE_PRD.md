# 도깨비 마트 2주차 PRE-PRD

작성일: 2026-11-14
기준 자료: `魑마트_기획서.pptx`, `魑마트_발표.pptx`, `1주차/PRD.md`
상태: 작업 범위 초안

## 문서 목적

기획서와 발표 자료의 5주 개발 일정 중 2주차에 해당하는 작업 범위를 정리한다. 1주차의 시작·닉네임·로비 흐름을 바탕으로 장보기 화면과 상품·인벤토리의 기본 구조를 준비한다.

## 2주차 목표

**마트 지도와 매대 화면을 만들고, 상품 종류·요구 수량·카트 인벤토리를 다룰 수 있게 한다.**

이번 주 결과물은 캐릭터와 도깨비가 없어도 테스트 입력으로 상품을 찾고 담거나 버리는 흐름을 확인할 수 있는 장보기 프로토타입이다.

## 주요 작업

- [ ] 마트 탑뷰 지도와 통로·매대·계산대·카테고리 구역을 구성한다.
- [ ] 매대뷰를 만들고 탑뷰와 매대뷰 사이를 오갈 수 있게 한다.
- [ ] 유제품·빵·화장품·야채·과일의 상품 데이터와 표시 이름을 준비한다.
- [ ] 판마다 상품 배치와 장보기 목록을 생성한다. 카테고리 위치는 고정하고, 판이 시작된 뒤 상품 배치는 해당 판 동안 유지한다.
- [ ] 상품별 요구 수량과 카트 인벤토리의 보유 수량을 관리한다.
- [ ] 매대에서 상품을 선택해 인벤토리에 담는 동작을 구현한다.
- [ ] 인벤토리에서 상품과 수량을 확인하고, 잘못 담거나 초과한 상품을 버리는 동작을 구현한다.
- [ ] 목록·매대·인벤토리의 정보가 서로 일치하는지 확인하고 실행 방법과 남은 작업을 기록한다.

## 화면과 동작 초안

### 마트 탑뷰

- 여러 세로 통로와 위·아래 가로 연결 통로를 표현한다.
- 유제품·빵·화장품·야채·과일 구역은 매 판 같은 위치에 둔다.
- 플레이어·도깨비·카트의 실제 이동은 이번 주 범위에서 제외한다. 위치 표시는 필요하면 다음 주 연결을 위한 임시 표시로 둔다.

### 매대뷰

- 양쪽 매대와 가운데 통로가 보이도록 구성하고, 상품명과 선택 가능한 상품을 표시한다.
- 탑뷰와 매대뷰 전환, 매대 구간 선택은 우선 테스트 입력으로 동작시킨다. 실제 캐릭터 위치에 따른 진입·이동 연동은 3주차에 연결한다.
- 상품 배치가 무작위여도 같은 판 안에서는 다시 방문했을 때 동일하게 보인다.

### 장보기 목록과 인벤토리

- 장보기 목록에는 상품명과 요구 수량을 표시한다. 한 카테고리에서 여러 상품을 요구할 수 있고 상품마다 수량이 다를 수 있다.
- 인벤토리에는 카트에 담긴 상품별 보유 수량을 표시한다.
- 매대에서 담으면 해당 상품의 보유 수량이 증가한다. 인벤토리에서 버리면 보유 수량이 감소하며, 0개가 되면 항목을 정리한다.
- 목록 밖 상품이나 요구 수량보다 많이 담는 것은 허용한다. 정확한 목록 일치 판정과 계산 성공·실패 처리는 3주차 작업으로 남긴다.

## 이번 주 범위에서 제외할 작업

- 플레이어와 카트의 이동·분리·재결합
- 도깨비 추적·탈취·도주·공격·상품 회수
- 제한시간과 스테이지 성공·실패 처리
- 계산대의 목록 일치 검사와 성공 보수 지급
- 접속별 2단계 해금, 누적 기여도·공용 자금 저장, 랭킹과 인수 엔딩

위 기능은 기획서의 3~4주차 일정에 맞춰 후속 작업으로 연결한다. 2주차 프로토타입의 테스트용 담기·버리기는 스테이지 성공, 보수, 해금 또는 저장 상태를 변경하지 않는다.

- [ ] 상품을 모두 버린 뒤 해당 인벤토리 항목이 남지 않는다.
- [ ] 임시 리소스를 포함해 실행에 필요한 이미지와 글꼴의 경로가 확인된다.

### 1. 판 시작 시 상품 목록 및 배치 무작위 설정 규칙

- 게임 시작 시 **카테고리와 대주제의 순서는 고정**하며, 각 대주제에 포함된 상품의 배치 순서만 무작위로 변경한다.
- 예를 들어 [커피]에 아메리카노, 카페라떼, 모카라떼, 플랫화이트 총 4개의 상품이 있다면, 해당 4개 상품의 순서만 무작위로 배치한다.
- 4개 상품의 배치 경우의 수는 **4! = 24가지**이며, 다른 대주제의 상품과 서로 섞이지 않는다.
- 상품 아이콘은 개별 브랜드나 상품명에 따라 구분하지 않고, 총 **11종의 공통 아이콘**으로 표현한다.
  - 유제품: 우유, 요플레, 치즈, 버터, 요구르트
  - 빵: 소금빵, 식빵
  - 음료: 음료
  - 라면: 봉지라면, 컵라면
  - 과자: 과자봉지
- 동일한 유형의 상품은 같은 아이콘을 사용하되, 상품명은 텍스트로 구분한다.

### 2. 인벤토리 상품 버리기 기능

- 인벤토리 UI는 `魑마트_발표.pptx`의 게임소개 페이지에 포함된 장보기 목록 및 인벤토리 이미지를 참고하여 구현한다.
- 플레이어가 인벤토리에서 버리고 싶은 상품을 **한 번 클릭하면 해당 상품 1개가 즉시 버려지는 방식**으로 구현한다.
- 별도의 수량 입력이나 확인 절차 없이 클릭만으로 상품을 버릴 수 있도록 한다.

### 3. 매대뷰 상품 표시 및 구간 이동 방식

- 탑뷰와 매대뷰의 화면 구성은 `魑마트_발표.pptx`의 게임 기획 페이지에 포함된 이미지를 기준으로 구현한다.
- 매대뷰에서 한 화면에 표시되는 상품 수와 배치 형태는 기획 이미지의 구성을 우선 적용한다.
- 상품은 대주제별로 구분하여 표시하며, 각 대주제 내부에서만 상품의 배치 순서가 무작위로 변경되도록 한다.
- 매대 구간 이동 방식은 기획 이미지의 화면 구성과 실제 구현 결과를 고려하여 결정한다.

확정되지 않은 수치는 임의로 게임 규칙에 고정하지 않는다. 우선 테스트가 가능한 단순한 임시값을 사용하되, 실제 게임 밸런스와 조작 방식은 3주차 통합 전에 확인한다.

## 2주차 완료 모습

장보기 화면에서 다섯 카테고리의 매대를 확인하고, 장보기 목록의 상품과 수량을 보면서 상품을 카트 인벤토리에 담고 잘못 담은 상품을 버릴 수 있다. 같은 판 안에서는 상품 배치가 유지되며, 캐릭터·도깨비·계산·보상 기능은 아직 연결되지 않은 상태임을 문서에 남긴다.
