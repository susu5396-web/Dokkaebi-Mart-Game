# 로비 구현 안내

## 실행

Python 3.12 / Windows / pico2d 환경에서 실행한다. 한글 글꼴은 Windows의 `malgun.ttf`, `malgunbd.ttf`를 사용하며 글꼴 파일 자체는 저장소에 복제하지 않았다.

프로젝트 루트에서:

```powershell
python "1주차/main.py"
```

`1주차` 폴더에서는 `python main.py`로 실행한다. 리소스는 실행 위치가 아닌 `settings.py` 위치를 기준으로 찾는다.

## 사용 흐름

1. 시작 화면의 게임 시작 버튼을 클릭한다.
2. 최대 12자의 닉네임을 입력하고 Enter 또는 완료 버튼을 누르면 곧바로 로비에 입장한다.
3. STAGE 1을 선택하고 게임 시작 버튼을 누르면 임시 스테이지 화면에 진입한다.
4. 로비로 돌아가면 닉네임은 유지되고 스테이지 선택은 해제된다.
5. STAGE 2는 잠겨 있으며 클릭하면 해금 조건만 안내한다.
6. 로그아웃하면 닉네임·선택 단계·접속 중 해금 상태를 초기화하고 시작 화면으로 돌아간다.
7. 종료 버튼, Esc 또는 창 닫기로 종료한다.

참고 이미지의 별도 게임 시작 버튼을 반영해 스테이지 선택과 입장을 두 단계로 나눴다. PRD의 1단계 클릭 즉시 진입 설명과 달라진 부분이다.

PRD에 따라 기여도와 공용 자금은 `0원 (임시)`, 목표는 `미정`, 순위는 빈 상태로 표시한다. 참고 이미지의 가상 금액·순위·자동 저장 안내는 실제 데이터처럼 표시하지 않는다. 중복 닉네임 검사는 이번 범위에 없어 입력 카드의 안내도 `닉네임 · 최대 12자`로 맞췄다.

## 수정 위치

| 파일 | 수정할 내용 |
| --- | --- |
| `main.py` | 이벤트 처리, 화면 전환, 공통 실행 루프 |
| `settings.py` | 800×600 창 크기, 시작 버튼 크기, 이미지 폴더, 네이비 색상, 개발 모드 |
| `ui.py` | 닉네임 입력 화면 문구와 디자인 |
| `lobby.py` | 로비 문구·배치·버튼 영역, 스테이지와 엔딩 미리보기 |
| `session.py` | 닉네임, 선택 단계, 해금 상태 |
| `lobby assets/images/lobby/` | 개별 PNG 에셋과 그리기 범위 |

배치 좌표는 800×600 기준이다. 창 크기를 변경할 때는 로비와 닉네임 화면의 좌표도 함께 조정해야 한다. `lobby.py` 상단의 `STAGE_ONE`, `STAGE_TWO`, `PLAY`, `LOGOUT`, `QUIT` 등은 그리기와 클릭 판정에 함께 쓰인다.

## 개별 이미지

이미지는 내장 `image_gen`으로 각각 생성했다. 도깨비는 기존 `dokkaebi_sheet1.png`의 외형을 참조하고, 사용자의 수정에 따라 송곳니를 파란색으로 맞췄다. 원본 스프라이트 파일은 변경하지 않았다.

| 파일 | 용도 |
| --- | --- |
| `market_banner.png` | 가로로 확장한 상단 마트 외관. 오른쪽 계정 패널과 분리 |
| `dokkaebi_clean.png` | 흰 외곽선을 정리한 1단계 도깨비. 2단계는 같은 이미지를 회색 실루엣으로 표시 |
| `coin_icon.png` | 공용 인수 자금 아이콘 |
| `cart_icon.png` | 스테이지 선택 아이콘 |
| `crown_icon.png` | 기여도 아이콘 |
| `lock_icon.png` | 잠금 아이콘 |
| `panel_flat.png` | 자금·선택·기여도·미리보기 패널. 9분할 렌더링으로 테두리 유지 |
| `stage_card_flat.png` | 선택 가능한 스테이지 카드 |
| `stage_locked_flat.png` | 잠긴 스테이지 카드 |
| `button_primary.png` | 게임 시작·로비 복귀 버튼 바탕 |
| `button_secondary.png` | 로그아웃·종료·선택 전 시작 버튼 바탕 |
| `badge.png` | 단계 안내, 선택 상태, 순위 헤더 바탕 |
| `progress_track.png` | 목표 미정 상태의 비어 있는 진행률 바 |

문구·닉네임·금액은 수정하기 쉽도록 이미지 위에 코드로 출력한다. `bounds.json`은 사용 중인 이미지의 소스 사각형(왼쪽, 위, 오른쪽, 아래)을 담는다. PNG 크기나 여백을 변경하면 이 값도 맞춰야 한다. PNG는 원본 해상도로 보관하며 화면에서 축소한다.

`prompts.json`, `refinement-prompts.json`, `banner-prompt.json`, `edge-prompt.json`에 내장 image_gen으로 사용한 생성·편집 프롬프트를 기록했다. 이전 로고·배경·마트·도깨비 및 패널 디자인도 비교용으로 보관하지만 `bounds.json`에 등록된 에셋만 실행 중에 로드한다.

## 검증

```powershell
python "1주차/test_lobby.py"
```

SDL 창과 실제 폰트·이미지를 사용해 10개 테스트를 실행한다. 닉네임 공백·길이·한글 문자 이벤트·Backspace, 잠금 처리, 3회 왕복, 로그아웃 초기화, 개발용 엔딩 상태 보존, 키 반복과 같은 프레임의 잔여 입력 차단, 종료를 검증한다. 한글 조합은 SDL 이벤트 주입으로 검증했으며, 실제 Windows IME 키보드 조작 검증과는 구분한다.

개발용 엔딩은 `settings.py`의 `DEVELOPMENT_MODE = True`일 때만 로비에 표시된다. 미리보기는 기여액 지급이나 해금을 발생시키지 않는다.

실제 장보기 플레이·1단계 성공 판정·2단계 해금·랭킹 집계·영구 저장은 이후 구현 범위다.


## 로비 디자인 보정

- 게임 로고와 상단 도깨비를 제거하고 가로형 `market_banner.png`를 상단 왼쪽에 크게 배치했다.
- 닉네임·로그아웃·종료는 오른쪽 `ACCOUNT_PANEL` 안에 배치한다. `HEADER_MARKET`과 영역을 분리해 그림 위에 글자가 겹치지 않는다.
- 로비 및 미리보기의 배경·패널·스테이지 카드는 연한 네이비 계열이다. 원본 패널 PNG를 덮어쓰지 않고 SDL의 텍스처 색상 변조로 적용한다.
- 색상은 `settings.py`의 `LOBBY_BACKGROUND`, `LOBBY_PANEL`, `LOBBY_STAGE`, `LOBBY_LOCKED`, `LOBBY_ACCOUNT`, `LOBBY_MUTED`에서 조정한다.
- `ui.py`의 `load_ui_image()`는 이미지 텍스처에 선형 보간을 명시해 고해상도 그림을 축소할 때 계단 현상을 줄인다. 실제 SDL 텍스처의 보간 모드도 확인했다. 이미지 자체의 외곽선은 별도로 정리했다.
- 시작 화면 이미지는 `start assets/`에서 불러온다. 닉네임 배경은 기존 `name_background.png`를 사용한다.

최종 로비 화면은 [previews/lobby.png](previews/lobby.png)에서 확인할 수 있다. 실제 Windows IME 키보드 입력 검증은 아직 별도 확인이 필요하다.

이번 보정 후 기존 SDL 흐름 테스트 10개가 모두 통과했다. 로비, 12자 한글 닉네임, 임시 스테이지를 각각 렌더링해 상단 계정 패널의 글자·버튼 겹침이 없음을 확인했다.
