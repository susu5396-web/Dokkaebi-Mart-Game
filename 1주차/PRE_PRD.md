# 도깨비 마트 1주차 PRE-PRD

작성일: 2026-11-05
상태: 초기 목표 확인 및 조정

## 문서 목적

본 PRD 작성 전에 1주차 목표와 작업 범위를 확인하고 수정한다. 세부 요구사항, 구현 방법, 검증 기준은 목표를 정리한 뒤 본 PRD에서 작성한다.

## 1주차 목표

**게임의 디자인 방향을 정하고, 기본 화면 흐름을 실행할 수 있게 만든다.**

## 주요 작업

- **디자인 준비:** 플레이어·도깨비·카트·빗자루의 기본 스프라이트와 UI 스타일 정리.
- **기본 화면 구성:** 시작, 닉네임 입력, 로비·스테이지 선택, 엔딩 화면 준비(게임 구현후 완성)
- **화면 전환 연결:** 시작,닉네임 입력 → 로비,스테이지 선택 흐름 구현.
- **화면 문구 작성:** 안내 문구, 버튼 이름, 엔딩 문구 정리.

엔딩은 개발용 미리보기로 확인하고, 실제 목표 달성 조건은 4주차에 연결한다.

## 이번 주 완료 모습

게임을 실행해 닉네임을 입력하고 1단계를 선택할 수 있다. 2단계는 잠금 상태로 표시되며, 기본 디자인과 엔딩 화면을 확인할 수 있다.

마트 탐색·상품 수집·도깨비 행동은 이후 주차에 구현한다.

## 먼저 확인하고 조정할 내용

- [ ] 1주차 화면 구성과 작업량이 적절한가?
- [ ] 기본 스프라이트를 어디까지 만들 것인가? = 도깨비 캐릭터, 플레이어 캐릭터 애니메이션 스프라이트 & 마트 디자인 및 매대 뷰 디자인 물건 디자인, ui디자인 게임시작화면 등등
- [ ] 디자인과 화면 구현 중 무엇을 먼저 진행할 것인가? = 세부 디자인 구현 -> 디자인화면구현


## 오늘의 시작점

목표와 범위를 검토하고, 화면별 구성 요소와 필요한 이미지 목록을 간단히 정리한다. 정리된 내용을 바탕으로 본 PRD와 세부 실행계획을 작성한다.
